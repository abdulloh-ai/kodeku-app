1. Pengenalan HTML5 & Tag Semantic

HTML (HyperText Markup Language) adalah bahasa standar dasar yang digunakan untuk menyusun elemen dan dokumen halaman web. Tag HTML5 semantic membantu mesin pencari (SEO) dan browser memahami hierarki dokumen web Anda secara tepat.

💡 Tips Penting: Selalu gunakan tag semantic seperti <header>, <main>, dan <footer> daripada menggunakan tag <div> secara berlebihan!

Contoh Kode HTML5 Semantic:

<header class="navbar"> <h1>Selamat Datang Di Web Saya</h1> </header> <main class="content"> <article> <h2>Judul Artikel Materi</h2> <p>Ini adalah isi paragraf materi koding.</p> </article> </main>
